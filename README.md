# 暗唱トレーニング（M1）

声に出すステップ（まとめ 4-1）で10文を練習できる状態です。

- 段階1：日本語訳だけを見て、英文を思い出して言う（記録に残るのは1回目の結果）
- 段階2：お手本を聞いてまね、🎤で何度でも確かめる（英文は隠した状態から始まる）
- 一発OKにならなかった文、「またあとで」を選んだ文は、他の文を3つ挟んでからもう一度出る（まとめ 2-3）
- 学習の記録は端末（IndexedDB）に残り、結果画面からCSVで保存できる

まだ入っていないもの：意味理解・構造把握・空欄補充・並べ替え、段方式のスケジュール、端末への保存（オフライン化）、保護者向けの設定、クラウド同期。

## フォルダの構成

```
index.html
css/app.css
js/            アプリ本体
data/          問題データ（tools/build_data.py で作る）
audio/         音声（tools/generate_audio.py で作る。なくても動く）
tools/         データと音声を作るスクリプト
```

## 準備（最初に1回）

```
py -m pip install openpyxl lameenc
```

## 問題データを作る

このフォルダで実行します。Excel を直したら、そのたびに実行してください。

```
py tools/build_data.py 問題データ作成フォーマット_10文試作用.xlsx
```

シート間の食い違い（05と08の語、07の空欄位置と正解など）があると、どこが違うかを表示して止まります。

## 音声を作る

1. Google Cloud の API キーを `tools/tts_api_key.txt` に1行で書く
2. まず1文で声を確かめる

```
py tools/generate_audio.py 問題データ作成フォーマット_10文試作用.xlsx --only S0001
```

3. よければ全件を作る（`--only` を外す）

音声がまだない間は、ブラウザの読み上げで代用します（ホーム画面にその旨が出ます）。

## 端末で使う

マイクを使うため、HTTPS で配信する必要があります。GitHub Pages にこのフォルダを置き、Android の Chrome で開いてください。

- `tools/tts_api_key.txt` は `.gitignore` で除外してあります。リポジトリに入らないことを必ず確認してください
- 公開リポジトリの GitHub Pages は誰でも見られます。教科書の例文と音声を置くことになるため、500文に広げる前に配信方法を決めます（まとめ 15-11）

## 試してほしいこと

- 段階1で、日本語を見て考えてから🎤を押し、言い切ったところで判定されるか
- 文の途中で詰まったとき、続きを言えばつながって判定されるか
- 段階2で、英文を隠したままお手本をまねる練習がしやすいか
- 一発OKにならなかった文が、少し後にもう一度出てくるか

結果画面の「CSVで保存」で、どの文で何と聞き取られたかを確認できます。
